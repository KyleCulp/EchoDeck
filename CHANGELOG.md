# Changelog

All notable changes to EchoDeck are documented here.

## [Unreleased]

### Added
- Project renamed to **EchoDeck** and set up as an open-source repo (MIT license, contributing/security/CoC, issue & PR templates, CI/release workflows, dependabot).
- Full design contract under [`plans/`](plans/) covering the audio engine, NVIDIA effects, virtual mic, device switching, GUI/tray, build/deploy, profiles, and roadmap.

### Notes
- The repo currently contains the original NVIDIA-AEC console prototype (`Program.cs`). The `EchoDeck.Engine` / `EchoDeck.App` split and the GUI are tracked in [`plans/08-roadmap.md`](plans/08-roadmap.md).
